# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please report it 
responsibly rather than opening a public issue.

1. **Do not** open a public GitHub issue for the vulnerability.
2. Email the maintainer at `zhaoyanliang296@users.noreply.github.com` with a description 
   of the issue, steps to reproduce, and any known impact.
3. You should receive a response within 48 hours.
4. If confirmed, a fix will be prepared and a security advisory 
   will be published alongside the release.

## Supported versions

Only the latest release receives security updates. 
Older versions are not patched.

## Scope

- Vulnerabilities in this project's code
- Vulnerabilities in direct dependencies that affect this project
- Not in scope: issues in third-party services, social engineering, 
  or denial-of-service against infrastructure you do not own

## Disclosure timeline

- Day 0: vulnerability reported privately
- Day 1: maintainer acknowledges receipt
- Day 2-7: investigation and fix development
- Day 7-14: coordinated public disclosure with credit
